参加費"無料"で参加できるスポーツイベント！

ジョガスポでは、全国47都道府県で開催される「体験型イベント」と、常に同じ場所で行われる「常設校（湘南）」を開催しております。
常設校だけにとどまらず全国どこにでも進出することで、全ての子どもたちが平等にスポーツを楽しめる機会を提供いたします。

STRENGTH

POINT 1

平等

体験型イベントは47都道府県どこでも開催！全ての子どもたちが本物に触れるチャンスがあります。

POINT 2

家族

JOGASPOは大人から子どもまで楽しめるエンタメカレッジ！一生モノの家族の思い出に。

POINT 3

無料

参加に伴う費用は一切かかりません！その瞬間を全力で楽しみたい、ワクワクしたい、その心があれば参加可能です！

SCHOOL

スクール

ジョガスポでは、神奈川県2拠点でスクールを運営しています。
「体験型」を重視したスクールで、楽しみながらサッカーの基礎を学べる環境を提供しています。
地域の子どもたちが平等にスポーツを楽しめるよう、丁寧に指導しています。

EVENT

イベント
